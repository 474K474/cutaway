# Cutaway — план разработки

Портфолио-визитка: проекты — пластинки в деревянном ящике. Ведёшь курсором вдоль ящика → пластинка выезжает → клик → она встаёт на проигрыватель, рядом карточка проекта.

- Репозиторий: https://github.com/474K474/cutaway
- Сайт: https://474k474.github.io/cutaway/ (деплой на GitHub Pages автоматически при пуше в `main`)
- Стек: Vite + React + TypeScript, three.js + React Three Fiber
- Коммиты — от имени владельца, без упоминания ассистента

## Концепция и стиль

- Тёмная тёплая комната, свет сверху (источник за кадром), при загрузке свет моргает и плавно разгорается.
- Брутализм / постеры в 2–3 цвета **только на обложках** пластинок (зерно, растр, огромный кондансед-шрифт Oswald). Интерфейс — спокойный гротеск Onest + курсив Cormorant Garamond.
- Акцентный цвет `#E0452C`, фон `#12100E`, текст `#F2ECE2`.
- Ящик стоит по диагонали, «лицом» вправо-вниз. Выбор пластинки — положением курсора, не колесом.
- Стороны: **A — работа и клиенты**, **B — пет-проекты и учёба**, между ними картонный разделитель.
- Физика переходов: при снятии сначала поднимается игла и уходит тонарм, диск замедляется, и только потом пластинку поднимают поверх деталей.

## Как проверять

1. Вкладка **Actions** в репозитории — зелёная галочка значит сайт собран и опубликован.
2. Сайт обновляется через 1–2 минуты после пуша: https://474k474.github.io/cutaway/
3. Вкладка **Commits** — что именно поменялось.
4. Локально: `git clone`, `npm install`, `npm run dev`.
